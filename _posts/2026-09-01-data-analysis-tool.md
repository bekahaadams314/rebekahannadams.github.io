# Project Overview
This project solves the problem of messy spreadsheet ingestion by building an automated parser.

### Key Features
* Cleans null fields automatically using a fallback matrix.
* Generates monthly trend graphs using Matplotlib.
* Exports directly to a PostgreSQL database.
